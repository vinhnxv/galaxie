# MVP exit record

Date: 2026-10-30. Evidence baseline: `main` commit
`0e9517326c0dbcab3c5a5854022c741a11467020` (the implementation branch started
at `21b384af48bdb6fda88f17161ae89f7a0f0e9239`, which adds only the reviewed

under [brief §18](galaxie-project-brief.md#18-verdict-demonstrations-and-engineering-checks-adr-0016).

tests on Node and headless Chromium after that baseline, using mocks only.

## Reading the evidence

The requirements and short names below come from
[brief §17](galaxie-project-brief.md#17-acceptance-tests--the-definition-of-done).
`automated` means the cited tests exercise the stated requirement within their
documented scope; it is not a result for an arbitrary host or real model.
`automated + real-device demonstration` also has an existing M2 or M3 observation.
`partial` means a part of the full requirement lacks evidence; `gap` means no
evidence exists. Test names are quoted verbatim, including parameter templates.

Automated model calls use scripted mocks, fake engines, fake `LanguageModel`
implementations or injected fetch; HTTP and MCP deployments are loopback
fixtures. The [device matrix](device-matrix.md#automated-lanes) describes the
Node 24 and headless Chromium lanes. `.node.test.ts` is Node only; React DOM and
IndexedDB-specific tests run in Chromium. An old exit record's “not yet built”
list describes that historical slice; current evidence below takes precedence.
